# Canvas source: Mom's screens

Source files of the Claude Design canvas "Family Memory — Mom’s screens":
https://claude.ai/artifact/YJYZpBYg8orLg8C2P3oJur

- `canvas.json` — the canvas index (artboard positions, sizes, titles, group headings).
- `*.dc.html` — one file per screen. They load `./support.js` from the Design canvas runtime, so they render in the canvas, not when opened directly.

PNG exports and notes per flow are in `design/01-…` to `design/05-…`.
